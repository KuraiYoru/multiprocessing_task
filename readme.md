# Задача Дирихле для уравнения Пуассона: параллельные волновые схемы

Метод Гаусса-Зейделя и три его параллельных варианта на `multiprocessing`
(по главе 6 пособия Гергеля В.П., Стронгина Р.Г.).

```bash
python dirichlet_parallel.py 300 4      # N = 300, 4 процесса
```

## Задача

### `make_problem(N)`
Создаёт задачу Дирихле для уравнения Пуассона на сетке `(N+2) x (N+2)`.
Внутренние узлы заполняются нулями (начальное приближение), на границе задаются
значения из примера пособия (п. 6.1), `f = 0`.
Возвращает `(u, f, h)`: сетку, правую часть и шаг сетки.

### `exact_solution(N)`
Точное решение тестовой задачи: `u(x, y) = 100 * (1 - 2x) * (1 - 2y)`.

### `max_diff(a, b)`
Максимальное по модулю отличие двух сеток одинакового размера.

## Алгоритмы

### `solve_poisson_sequential(u, f, N, h, eps, max_iter)`
Последовательный метод Гаусса-Зейделя (алгоритм 6.1 пособия).
Узлы обходятся построчно слева направо, сверху вниз; новое значение сразу
записывается в `u`, поэтому верхний и левый соседи берутся уже с текущей итерации,
а нижний и правый - с предыдущей. Итерации повторяются, пока максимальное
изменение `dmax > eps`.
Изменяет `u` на месте. Возвращает число выполненных итераций.

### `solve_poisson_wavefront(u, f, N, h, eps, max_iter, num_procs)`
Волновой метод Гаусса-Зейделя по узлам (алгоритм 6.5 пособия).
Итерация разбивается на `2N-1` шагов по антидиагоналям сетки; узлы одной
диагонали считаются параллельно. Результат побитово совпадает
с `solve_poisson_sequential`.
Изменяет `u` на месте. Возвращает `(число итераций, время счёта в сек)`.

### `solve_poisson_blocks(u, f, N, h, eps, max_iter, num_procs, block_size)`
Волновой метод Гаусса-Зейделя по блокам (алгоритм 6.6 пособия).
Сетка делится на блоки `block_size x block_size`, волна идёт по антидиагоналям
блоков; внутри блока обход построчный. Барьеров на итерацию `2*nb-1` вместо `2N-1`.
Результат побитово совпадает с `solve_poisson_sequential`.
Изменяет `u` на месте. Возвращает `(число итераций, время счёта в сек)`.

### `solve_poisson_cache(u, f, N, h, eps, max_iter, num_procs, block_size, time_steps)`
Блочная волна сразу для нескольких итераций (множественная волна, п. 6.3).
За один заход выполняется `time_steps` итераций: блок `(bi, bj)` на шаге `t`
обрабатывается на волне `w = bi + bj + 2t`. Значения после каждой итерации
совпадают с `solve_poisson_sequential`, но условие остановки проверяется раз
в `time_steps` итераций, поэтому итераций может быть до `time_steps-1` больше.
Изменяет `u` на месте. Возвращает `(число итераций, время счёта в сек)`.

## Служебные функции

### `_run_parallel(target, u, f, N, h, eps, max_iter, num_procs, extra)`
Общий запуск параллельного алгоритма на процессах. Копирует сетку `u` в общую
память, создаёт общие объекты синхронизации (`dmax`, замок, барьер, флаг остановки,
счётчик итераций, время), запускает `num_procs` процессов с функцией `target`,
ждёт их завершения и копирует результат обратно в `u`.
Возвращает `(число итераций, время счёта в секундах)`.

### `_worker_wavefront(...)`
Процесс волнового алгоритма по узлам. Перебирает антидиагонали `nx = 1 .. 2N-1`
(узлы с `i + j = nx + 1`). Узлы одной диагонали независимы и делятся между
процессами непрерывными кусками; после каждой диагонали - барьер. Погрешность
пишется в общий `row_max[i]` без замков: на одной диагонали в каждой строке
ровно один узел.

### `_worker_blocks(...)`
Процесс волнового алгоритма по блокам. Сетка разбита на блоки `B x B`.
Перебираются антидиагонали блоков `nx = bi + bj = 0 .. 2*nb-2`; блоки одной
диагонали независимы и раздаются процессам по кругу. После каждой диагонали -
барьер. У каждого процесса своя `local_dmax`, которая один раз за итерацию
сливается в общую `dmax` под замком.

### `_worker_cache(...)`
Процесс волнового алгоритма по блокам и итерациям. За один заход выполняется пачка
из `steps = min(T, остаток)` итераций. Блок `(bi, bj)` на шаге `t` пачки
обрабатывается на волне `w = bi + bj + 2t`: к этому моменту верхний и левый
соседи уже на шаге `t`, а нижний и правый - на шаге `t-1`. Задачи волны
раздаются по кругу, после волны - барьер. Погрешность считается только
на последнем шаге пачки.

### `_cache_wave_tasks(w, steps, nb)`
Задачи `(t, bi, bj)` одной волны `w = bi + bj + 2t`. Перебор сначала по `t`,
потом по `bi`; комбинации с `bj` вне сетки блоков отбрасываются.

### `_relax_block(u, W, f, h2, N, B, bi, bj, track)`
Один проход Гаусса-Зейделя по блоку `(bi, bj)` размера `B x B`. Строки блока
обрабатываются сверху вниз, узлы в строке - слева направо, как в последовательном
алгоритме. Из общей памяти копируется только кусок строки ширины блока плюс
по одному соседу слева и справа. Если `track=True`, возвращает максимальное
изменение в блоке, иначе 0.

### `_attach(shm_name)`
Подключается к общему блоку памяти и возвращает `(shm, u)`. `u` - плоский массив
`double`: узел `(i, j)` лежит по индексу `i * (N + 2) + j`.

### `_static_range(lo, hi, rank, nprocs)`
Непрерывный кусок индексов `[lo, hi]` для процесса `rank`: диапазон делится
на `nprocs` почти равных подряд идущих частей.

### `_merge_dmax(local_dmax, dmax, dmax_lock)`
Сливает локальную погрешность процесса в общую под замком.

### `_decide(rank, steps, eps, max_iter, sync)`
Проверка условия остановки после очередной итерации (пачки итераций).
Процесс 0 увеличивает счётчик итераций на `steps` и решает, продолжать ли счёт
(`dmax > eps` и `iter < max_iter`). Затем барьер, чтобы решение увидели все.
Возвращает `True`, если пора остановиться.
